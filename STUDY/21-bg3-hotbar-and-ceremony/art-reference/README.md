# ⚠⚠ REFERENCE ONLY — LARIAN ART. NOTHING HERE MAY SHIP.

These are **Baldur's Gate 3 files**, extracted from `Game.pak`
(`Public/Game/GUI/Assets/BottomBar/`) and converted DDS→PNG, so that a design
conversation can happen against the real thing instead of a description.

**`ASSET-REPLACEMENT-01`, the standing rule:**

> *reuse the source games' assets as reference, then recreate them close but ours.*

**⚠ AND BG3 IS NOT EVEN A SOURCE GAME.** `PT-1350` offers extraction **from the
user's own copy of KOTOR**, because the product is a KOTOR-alike and the user
owns KOTOR. **That bargain does not extend to Baldur's Gate 3.** There is no
version of this where a Larian PNG reaches a player through us.

**So:** the *idea* of a ring is free. **This ring is not.** If a ring goes on a
tile, it is drawn by us.

**⚠ `ASSET-REPLACEMENT-01` exists because a source asset is indistinguishable
from a finished one once it looks right in context.** That is exactly the risk
of a folder of good-looking rings sitting in the tree. It is why this file is
here.
