## Traps learned (each cost time)
- **xdotool `key --window` does nothing here** (no window manager on Xvfb: focus is the root window and Flutter ignores the synthetic events). `k.sh` does `windowfocus` then plain `xdotool key`; `xdotool type` works after windowfocus.
- **`$!` after `cd … && nohup app &` is the wrapper's PID**, not the app's: launch with `( cd … && exec app ) &`.
- The 10×10 helper window now sits at (10,10); `win.sh` picks the 1920×1080 one.
- **`ffmpeg -vf select=eq(n,N)` picks the wrong frame on a capture with gaps** (VFR vs the CFR decode); seek by time (`-ss N/60`) or dump from the raw decode.
- **A pixel detector whose region includes a static bright thing never "closes" a run** — the token ring sat inside my "white text" crop, so 'miss' read as never seen. Check the median of each feature before thresholding; layout shifts (1- vs 2-line log) give two baselines.
- **The board shifts a few pixels** when the bottom log has one line vs two; crops must tolerate ±8 px.
