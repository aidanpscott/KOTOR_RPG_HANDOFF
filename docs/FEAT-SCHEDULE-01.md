## Three more columns, authored rather than read — `PT-2490`, `PT-2553`

**Sith Warrior, Sith Assassin and Sith Inquisitor carry no column in the real K2 table above them, and never will** — they're this project's own base-class roster (`CLASS-ROSTER-01 §2`), not playable classes in the source game at all. **Their L20/L30 totals were already ruled** (the summary table near the top of this document: 14/20, 8/12, 7/11) — what was genuinely missing was the level-by-level breakdown, not the totals themselves. Each column is derived rather than invented outright:

    Sith Inquisitor    an EXACT mirror of Jedi Consular's own real cadence —
                        same rate (Specialist), same hit die (d6), and the
                        totals already matched (7/11), so no construction
                        was needed at all.
    Sith Warrior        Jedi Guardian's real cadence (Combat rate, d10) is an
                        alternating +2,+1 step from level 1, landing at
                        13/20. Phase-flipped to +1,+2 instead — same family,
                        opposite starting step — lands at 14/20 exactly,
                        the documented target, with the same total by 30.
    Sith Assassin       Jedi Sentinel's real cadence (Middle rate, d8) is a
                        repeating +2,+3,+1 triad landing at 10/15. A sparser
                        two-term +2,+3 alternation — the same small-integer-
                        step design language, fewer terms — lands at 8/12
                        exactly, the documented target.

**Not a literal Jedi mirror for two of the three**, because the documented totals genuinely differ from any rate-matched Jedi sibling's own total. Constructed from the SAME cadence grammar this whole table already uses (small alternating integer steps from level 1) rather than an arbitrary new shape, and calibrated to hit numbers this document had already ruled rather than inventing new ones.

## Seven schedules, fifteen classes

**Most classes share a cadence exactly.**

| Schedule | Classes | Feats by 30 |
|---|---|---|
| **1, 2, 3, then every odd** | **Scout · Guardian · Weaponmaster · Marauder** | **16** |
| **Every level to 16, then every other** | **Soldier** | **23** |
| **1, 3, 6, 7, 9, 12, 13, 15, 18, 19…** | **Sentinel · Watchman** | **15** |
| **1, 3, 5, 6, 9, 11, 12, 15, 17, 18…** | **Engineer** | **16** |
| **1, 3, then every third** | **Consular · Marksman · Jedi Master · Sith Lord** | **11** |
| **1, 2, then every third** | **Smuggler · Machinist · ⚠ Saboteur** | **11** |
| **Every third from 1** | **Sith Assassin** | **10** |

> **The prestige classes inherit their base class's rhythm.** **Weaponmaster and Marauder run the Guardian's. Jedi Master and Sith Lord run the Consular's.** **A character who prestiges does not change how often they gain feats.**

**Two exceptions.** **The Watchman matches the Sentinel — its own base class — which is consistent.** **The Assassin does not match anything**: a flat feat every three levels from 1, and **the only class in either game with a perfectly regular cadence.**

## What this settles about our own schedules

**`ATTACKS-01 §11.6` provisionally assigned Soldier and Guardian to the Combat attack rate, Scout and Sentinel to Middle, Smuggler and Consular to Specialist.**

**K2's feat table mostly agrees and corrects one thing.**

**The Guardian is not a middling feat class.** **K1's 9 read that way; K2's 11 puts it level with the Scout and Weaponmaster.** **Our top-rate assignment is right.**

**⚠ But the Scout is on the same schedule as the Guardian — 16 feats by 30 — while our attack rates put it a tier below.** **And the Sentinel at 15 sits just under both.**

> **The source groups Scout, Guardian, Weaponmaster, and Marauder as one class of character. Our attack schedule splits them across two rates.**

**⚠ And the Machinist runs the Smuggler's schedule exactly** — 11 feats — **where `SKILLS-01` gives it 6 base skill points against the Smuggler's 8.** **A different skill class, an identical feat class.**

**All of it belongs to the class workstream. Recorded here so it is not rediscovered.**
