# 5 — What is unresolved

## 5.1 ⚠ The Agent is superseded and the collision it was rebuilt to avoid is back

**`REPLY-29` moved it from `Charisma` to `Intelligence`, dropped impersonation for cover and gadgets, and withdrew `Cover Identity`.**

**⚠ `PT-135` put it on `Charisma` *specifically because* `Smuggler` and `Jedi Sentinel` each hold all four covert skills and `Charisma` was the only thing distinguishing it.** **That measurement has not changed. Moving the class off `Charisma` removes the distinction without replacing it.**

**And `Operative` above lists `Agent 6` as its entry, so the parent's premise is load-bearing for a class already adopted.**

**Its numbers in `§1` are the pre-rebuild ones and should not be trusted.**

**`Vanguard`** — no purpose anywhere in `docs/`.
