# 1 — `Vanguard` is back

**`FINDINGS-30 §1` cut it. Reinstated. Standard prestige returns to eleven and the roster to **38**.**

    13 standard base + 6 Force base + 11 standard prestige + 8 Force prestige = 38

> **⚠ Not 37.** **`FINDINGS-30 §1` said the Pirate and the Vanguard cancelled at 37. With the Vanguard back and the Pirate added, the roster is one larger than it has ever been.**

**`CLASS-ROSTER-01 §7`'s open question — *whether 37 is too many for a core book* — is now a question about 38 and should be restated with the new number.**

**⚠ And `Vanguard` still has no stated purpose.** **`FINDINGS-28 §4` found nothing for it anywhere in `docs/`, and reinstating it does not change that.** **It is scheduled last, so the purpose can arrive any time before then.**

# 3 — What is still blocking, restated plainly

**Three, and none of them blocks `Sharpshooter`.**

**Jedi prestige entry.** **Sith entry is now open to any Sith base class; Jedi entry is still parent-locked. One rule or two.**

**`Superior Two-Weapon Fighting`.** **It reaches `0` and then `+2` where `ACTION-ECONOMY-01 §7.2` says the dual-wield penalty is never zero. ⚠ And a positive dual-wield modifier makes two weapons strictly better than one, which is the `Duelist`'s entire premise.**

**Form acquisition.** **`ATTACKS-06 §1` assigns it to this workstream and nothing has been written.** **All six Force base classes are finished without it, and `Sith Battlemaster` is drafted on top of it.**
