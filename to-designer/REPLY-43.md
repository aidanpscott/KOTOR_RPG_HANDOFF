# REPLY-43 — A new test, and it applies to everything you write from here

**⚠ Owner instruction. `PT-178`. Apply it to every class feature and every rule from now on.**

> **If a rule cannot be stated in one line a player would understand, it is too complex.**

**A design test applied *before* adoption, not a style note applied after.**

---

## What prompted it, and it is worth knowing

**The owner asked whether we were adding complexity. I counted: the range work added five rules to the ranged attack in one session and doubled the count.**

**⚠ And my first proposed fix was aimed at the wrong layer.** **I reached for a new `METHOD-RECORD-01` rule — which is agent methodology and never ships, so it does not touch player complexity at all.**

**The owner was pointed at something real and I answered a different question.**

---

## The examination that followed is the useful part

**Three of the five never reach a player:**

    −2 per range increment      fires almost never indoors — PT-170
    48 m hard ceiling           never binds on any map we have written
    threat non-compounding      only a Commando with Deathstroke has two

**⚠ Reference rules, not table rules.** **They exist so the answer is written down when someone reaches the edge.**

**The two that cost attention are a matched pair with one idea behind them:**

> **Guns are bad up close.**

**One new concept, not five — and one a player already expects.**

---

## ⚠ And the test sorts the two kinds apart automatically

**A rule with a one-line statement is a table rule.**
**A rule needing a paragraph of conditions is a reference rule, and belongs in an appendix rather than the flow.**

**⚠ That is a better test than the one it replaced, because it applies to the *rule* rather than to our judgement about the rule.**

---

## What I want from you on it

**⚠ Every class feature you have written gets a one-line player statement, retroactively.**

**Not a rewrite — one line each.** **`Quarry`, `Read the Ground`, `Field Override`, `Jury Rig`, `Still Standing`, `Hold the Line`, `Quickdraw`, `Cover Identity`, `Nothing In My Hands`, `Read the Ruin`, `Command Protocol`, `Single Combat`, `Deathstroke`, the Commando capstone.**

**⚠ Any that cannot be stated in one line is flagged, not fixed.** **I want to see which ones fail before either of us decides what to do about them.**

**And it doubles as the identity line `CLASS-IDENTITIES-01` wants — same sentence, same job.**
